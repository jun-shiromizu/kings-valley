5×5マスの盤面で、駒を壁や他の駒にぶつかるまで真っ直ぐスライドさせ、自分の王様（メイン）駒を中央のマスにピタリと止めるアブストラクトゲーム

ゲームの基本ルール
- ボード: 5×5マス
- 駒: 各プレイヤーに王様（メイン）駒1個と兵士駒4個（計5個）
- 移動方法: 縦・横・斜めのいずれかに直進しますが、盤の端（フチ）か他の駒にぶつかるまで途中で止まることができません
- 勝利条件: 最初に自分の王様駒を盤の中央のマスにピタリと止める

本リポジトリでのゲーム
- トップページ
  - ｛先手、後手、ランダム｝を選んで「ゲームスタート」

- ゲームページ
  - 盤面が表示される
  - 手前がプレイヤー、奥がCOM
  - どちらの手番か分かるようにする
  - 自分の手番の場合は以下の操作
    - マウスクリックやタップで対象の駒を選択、動かせる方向が矢印で表示される
      - 対象の駒を選択した後で、再度クリック・タップすると選択解除
    - 矢印をクリックして駒を飛ばす
    - 勝敗決着判定をし、勝敗が決まらなければ手番交代
  - ゲームが終わると勝敗が大きく表示され、「もう一度」または「トップページ」を選択

- COMのアルゴリズム
  - とりあえずはランダムに駒を選び、ランダムに動かす

- アーキテクチャ
  - 認証無し
  - vue.js で実現
  - GitHub Pages にデプロイ
    - GitHub PagesへデプロイするGitHub Actionsの最小Workflow
  - スマホ、タブレット、PCを想定
